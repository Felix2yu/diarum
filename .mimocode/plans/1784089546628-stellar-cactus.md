# Plan: Add General Settings Tab + Default View Setting

## Context
Root redirect (`src/routes/+page.svelte:13`) hardcodes `goto(/diary/${getToday()})` — every authenticated user always lands on today's diary editor. User wants the option to land on the calendar view instead, and wants to explore what other settings could live in a new "通用" (General) tab.

## Changes

### 1. Add `GeneralSettings` interface to `src/lib/api/settings.ts`

```typescript
export interface GeneralSettings {
  default_view: 'diary' | 'calendar';
}

export async function getGeneralSettings(): Promise<GeneralSettings> {
  const value = await getSettingValue('app.default_view');
  return { default_view: value === 'calendar' ? 'calendar' : 'diary' };
}

export async function saveGeneralSettings(s: GeneralSettings): Promise<void> {
  const res = await fetch('/api/v1/settings/batch', {
    method: 'PUT',
    headers: { 'Authorization': `Bearer ${pb.authStore.token}`, 'Content-Type': 'application/json' },
    body: JSON.stringify({ settings: { 'app.default_view': s.default_view } })
  });
  if (!res.ok) throw new Error('保存失败');
}
```

### 2. Modify `src/routes/+page.svelte` root redirect

Replace hardcoded redirect with fetch-then-redirect:

```typescript
onMount(() => {
  if ($isAuthenticated) {
    getGeneralSettings()
      .then(s => goto(s.default_view === 'calendar' ? '/diary' : `/diary/${getToday()}`))
      .catch(() => goto(`/diary/${getToday()}`))
      .catch(() => { ready = true; });
  } else {
    ready = true;
  }
  // ... existing IntersectionObserver
});
```
